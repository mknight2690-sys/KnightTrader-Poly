How-To

Do these steps in order. This guide is written for someone who has never done this before.

Take it slow and follow the How-To tab. Paste the four Polymarket values, install the assistant, and let the five-minute job run.

Then open the Hermes tab, start the dashboard and gateway if they are not already up, and use Open in browser to confirm the job is completing cycles. The Trading tab reads the Polymarket account those keys belong to.

That's it.

—Matthew Knight, Founder, KnightTrader Poly
Before you start — do not skip this
  1. You need Windows 11 or an Apple Silicon Mac on macOS 11 or later.
  2. You need a Polymarket account that can hold pUSD. Start with an amount you can lose in full.
  3. You need four values from that account: API key, secret, passphrase, and the wallet private key.
  4. You need a Nous Portal key. Nous charges a one-time ~$5 credit top-up, paid to Nous, before it will create one.
  5. Plan on 30–60 minutes the first time. Keep the laptop plugged in.
  6. If Polymarket blocks your own network, use Proton's free VPN and land in Mexico or Romania (step 3). Poland, Singapore, and a generic Canada server are not safe for new orders.
A 5-minute crypto up/down contract can expire against you. The assistant is told to buy 5 shares — the exchange minimum — until the account is up 50% from its starting balance. That rule is not a promise that you will get there.
1
Install KnightTrader Poly
This installer is separate from KnightTrader BloFin. Both can be installed. They do not share a data folder, a port, or a tray icon.
  1. On Windows, double-click KnightTrader Poly Setup and finish the installer. Open KnightTrader Poly from the Start menu.
  2. On a Mac, open the .dmg, drag KnightTrader Poly into Applications, then right-click the app and choose Open if macOS says the developer cannot be verified.
  3. You should land on this How-To tab.
2
Keep this computer awake
The assistant only runs while this PC is on and online.
  1. On Windows, open Settings → System → Power and set sleep to Never while plugged in.
  2. On a Mac, open System Settings → Lock Screen (or Energy) and turn off sleep while on power.
  3. Leave the app running. Closing the window keeps it in the tray.
3
Use a free Proton country Polymarket allows
Free Proton usually connects you to the Netherlands, Mexico, Canada, Singapore, Romania, Poland, or Japan. Polymarket does not treat those the same. This follows Polymarket's geographic restrictions page. Recheck before you leave the VPN on, because the list can change.
Use these. They are not on the restricted list, so new orders are allowed on the site and the API: Mexico and Romania.
Netherlands and Japan: the Polymarket website is close-only there, but Polymarket says the API itself is not restricted. This app sends orders through that API. Use them only after the check below says you are not blocked.
Do not use these for new orders. Close-only on both the site and the API, so a new order from that IP is rejected: Poland and Singapore.
Do not use a generic Canada server. Polymarket blocks Alberta, British Columbia, Ontario, and Quebec on both the site and the API. Free Proton does not show which province you landed in.
  1. Open https://polymarket.com/api/geoblock before you turn a VPN on. If it says "blocked": false, skip Proton.
  2. If it says "blocked": true, install the free Proton VPN app, sign in, and connect to Mexico or Romania.
  3. If Mexico and Romania are not in the free server list, try Netherlands or Japan. Do not stop on Poland, Singapore, or Canada.
  4. Reload the geoblock page. Continue only when it says "blocked": false.
  5. Leave that Proton connection on while this app is running. If you disconnect and the check flips back to blocked, new orders from this PC will be rejected.
4
Create your Nous Portal API key
The model calls go through your Nous key. KnightTrader does not bill this.
  1. Open portal.nousresearch.com and sign in.
  2. Add a one-time credit top-up of about $5, paid to Nous.
  3. Create an API key and copy the whole value.
  4. In this app, open Setup, paste it into the Nous field, and click Test AI Credentials.
5
Put pUSD on Polymarket
The trading desk reads the Polymarket account you connect. Deposit only what you can lose.
  1. Open polymarket.com and sign in to the account you will trade.
  2. Deposit pUSD using Polymarket's own deposit flow. Collateral on CLOB v2 is pUSD, not USDC.e.
  3. Leave the funds in that account.
6
Paste the four Polymarket values
Setup, Polymarket CLOB keys. All four fields are required. They are stored encrypted on this PC.
  1. Paste the CLOB API key, secret, and passphrase.
  2. Paste the wallet private key (0x plus 64 hex characters) for that same account.
  3. Click Test Polymarket Credentials. A success line means the account read worked.
  4. If Polymarket rejects the pasted API key, the app derives CLOB credentials from the private key and retries the balance read.
Never paste these values into chat, email, or a screenshot. Anyone with the private key can sign for that wallet.
7
Install the assistant and the 5-minute job
The job is named separately from the BloFin app, so both schedules can exist.
  1. Open the Hermes tab and click Install Hermes.
  2. Start the dashboard and gateway if they are not already running.
  3. Click Auto-Configure Cron. The job runs every 5 minutes and uses Polymarket CLOB v2.
  4. Use Open in browser and confirm the job is scheduled.
Each pass scans crypto 5-minute up/down markets, including markets that end within those five minutes. Until the account is up 50% from its recorded start, the live bet is 5 shares, and only when the edge test passes.
8
Watch the Trading tab
  1. Open Trading. Cash and portfolio value should match the Polymarket account, in pUSD.
  2. Open positions, when you have them, show on the same desk.
  3. The equity curve fills from that account over time.
  4. Open Logs if a cycle looks wrong. Stop the schedule before you add more pUSD.
9
If something breaks, fix the first error
  1. Credential test fails: re-copy all four values. The private key must be 0x plus 64 hex characters. If the API key is stale, leave the private key in place and test again so the app can derive credentials.
  2. Balance is zero: confirm pUSD is in the Polymarket account for that wallet, including a proxy wallet if you deposited through the Polymarket site.
  3. Nous test fails: confirm the ~$5 credit posted and paste the full key created after the top-up.
  4. Geoblock says blocked: go back to step 3. Connect Proton to Mexico or Romania, then reload the geoblock check until it says blocked false. Do not use Poland, Singapore, or Canada.
  5. Dashboard blank: use Open in browser on the Hermes tab, or Reload desk on Trading.
  6. No orders yet: the job is allowed to do nothing when it cannot write down an edge. That is expected.
  7. Computer slept: wake it, then confirm the gateway is still running.
